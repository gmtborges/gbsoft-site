# GBSoft Site

Personal consulting site for Gustavo Martins T Borges, offering SRE / DevOps consulting to Brazilian and international clients.

## Language

**Default language**:
Brazilian Portuguese (`pt-BR`); every page exists in it first.
_Avoid_: main language, Portuguese (unqualified)

**Translation**:
The same page rendered in the other language, linked to its counterpart.
_Avoid_: version, copy, locale

**Consulting page**:
The page listing the SRE / DevOps services offered.
_Avoid_: services page, consultoria (in English text)
